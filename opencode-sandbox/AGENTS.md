# AGENTS.md — opencode-sandbox

**Precedence:** the closest `AGENTS.md` to the files you're changing wins. This file governs `opencode-sandbox/`; the sibling `../local-models/AGENTS.md` governs host model serving.

Runs OpenCode inside Docker Sandboxes (`sbx`, schema v2 kit) with the agentmemory MCP. Read [README.md](README.md) before changing the flow; [spec.yaml](spec.yaml) is the kit contract.

## Commands (host, Debian; installs take minutes)
| Task | Command | Notes |
|------|---------|-------|
| Install host deps | `./install-dependencies.sh` | sbx 0.48.0 + agentmemory 0.9.30; flags `--skip-docker-sandbox`, `--skip-agentmemory`; needs KVM |
| Sync repo config to host | `./sync-config.sh` | host only, never inside the sandbox; copies opencode.json, plugins/, commands/ into ~/.config/opencode |
| Enter sandbox | `./run-opencode-in-docker-sandbox.sh` | run from any project dir; sandbox name = basename of $PWD, reused if it exists |
| Reset sandbox | `sbx rm <name>` then relaunch | required after spec.yaml or agentmemory.env changes |

## File Map
| Path | Purpose |
|------|---------|
| spec.yaml | kit: `extends: opencode`, required `home` arg, network allowlist, pinned agentmemory install, secret export |
| opencode.json | providers (ollama/llama-server on 172.17.0.1), agentmemory MCP, permission rules, instructions |
| agentmemory.env | host agentmemory config (OPENAI_MODEL); copy to ~/.agentmemory/.env |
| run-opencode-in-docker-sandbox.sh | launcher: resolves AGENTMEMORY_SECRET, writes ~/.config/opencode/agentmemory-secret (0600), health-checks :3111 |
| sync-config.sh | repo to ~/.config/opencode; aborts when plugins/ or commands/ are symlinks (that is the sandbox view) |
| commands/recall.md, commands/remember.md | /recall and /remember slash commands over agentmemory tools |
| plugins/agentmemory-capture.ts | captures session events into the agentmemory REST API; dispose posts synchronously via curl |
| dependencies/ | generated by install-dependencies.sh; gitignored, never commit |

## Heuristics
| When | Do |
|------|-----|
| Changing opencode.json, plugins/, commands/ | run `./sync-config.sh`, restart OpenCode; no sandbox rebuild needed |
| Changing spec.yaml or agentmemory.env | recreate the sandbox (`sbx rm <name>`), then relaunch |
| Adding an agentmemory tool deny | put it after `"*": "allow"`; last matching permission rule wins |
| Host agentmemory health check fails | expected path; the sandbox runs a reduced local toolset until host :3111 is back |
| Calling agentmemory MCP tools | pass `concepts` and `files` as explicit structured arrays |
| Editing ~/.config/opencode directly | don't; it is a read-only mount in the sandbox, the repo is the source of truth |

## Boundaries
- Never commit secrets, the agentmemory-secret file, or anything under `dependencies/` (gitignored).
- Never call `sbx run` on the kit directly; the launcher supplies the required `home` kit arg.
- Ask first: changing `spec.yaml` schema or args, MCP deny rules, or pinned dependency versions.
